# Lesson 1 — Mobile Auth & Catalog App

Учебное мобильное приложение на React Native и Expo (TypeScript). Реализован полноценный флоу авторизации, регистрации и просмотра заведений города.

## 📱 Реализованные экраны

1. **Авторизация (Login)** — форма входа по номеру телефона и паролю с возможностью переключения видимости пароля.
2. **Регистрация (Register)** — создание учетной записи с валидацией и чекбоксом согласия с правилами.
3. **Выбор города (SelectCity)** — дропдаун выбора актуального города (Алматы, Астана и др.).
4. **Восстановление пароля (ForgotPassword)** — запрос номера телефона для сброса.
5. **Подтверждение номера (OtpVerification)** — 4-значный ввод OTP-кода с автоматическим фокусом на ячейках.
6. **Сброс пароля (ResetPassword)** — форма ввода и подтверждения нового пароля.
7. **Экран успеха (SuccessScreen)** — подтверждение завершения регистрации.
8. **Главный экран (HomeScreen)** — каталог заведений с категориями, рейтингом и поиском.
9. **Профиль (ProfileScreen)** — просмотр данных пользователя, смена города и выход из аккаунта.

## 🛠 Технологический стек

- **React Native** (Functional Components, Hooks)
- **Expo SDK**
- **TypeScript**
- **StyleSheet** (стилизация без сторонних UI-библиотек)
